# 06.app

Инициализация приложения. Код здесь выполняется один раз при старте.

| Файл            | Что делает                                                                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `websocket.ts`  | Vue-плагин с подключениями Socket.IO                                                                                                                         |
| `withI18n.ts`   | подключение Vue I18n                                                                                                                                         |
| `pwa.ts`        | в вебе регистрирует service worker и предлагает обновиться; на нативе удаляет service worker'ы и их кэши (офлайн там обеспечивает `features/map/OfflineMap`) |
| `deepLinks.ts`  | обработка deep links на нативе                                                                                                                               |
| `backButton.ts` | аппаратная кнопка «Назад» на Android                                                                                                                         |
