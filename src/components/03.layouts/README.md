# 03.layouts

Каркасы страниц, которые выбираются через `meta.layout` в маршруте:

- `DefaultLayout.vue` — основной каркас с нижней навигацией (`04.widgets/BottomNav`);
- `EmptyLayout.vue` — пустой каркас для приветствия, 404 и сброса пароля.

> Номер слоя ниже, чем у виджетов, но `DefaultLayout` импортирует `BottomNav`. Это исторический компромисс: layout по смыслу стоит на уровне страниц.
