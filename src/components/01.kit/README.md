# 01.kit

UI-кит: базовые компоненты без бизнес-логики (`UAvatar`, `UInput`, `UModalWrapper`, `USheet`, `UIcon` и т. д.).

- Каждый компонент лежит в своей папке `U<Name>/` с `index.ts` и `ui/`.
- Компоненты регистрируются **автоматически** через `unplugin-vue-components`, импортировать их вручную не нужно. Типы генерируются в `src/types/dts/components.d.ts`.
- Компоненты кита могут импортировать только `00.shared`.
