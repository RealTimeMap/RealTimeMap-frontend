# 04.widgets

Крупные самодостаточные блоки интерфейса, которые собирают несколько фич в одно целое.

| Виджет          | Что собирает                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------- |
| `Profile`       | экран профиля: уровень, достижения, статистика, метки; невидимый прогрев первого рендера (`ui/Warmup.vue`) |
| `ProfileStats`  | сводка статистики и модалка подробной статистики                                                           |
| `Settings`      | экран настроек: аккаунт, уведомления, тема, редактор карты, сессии, баг-репорт                             |
| `MapControls`   | кнопки управления картой: зум, слои, редактор, настройки                                                   |
| `BottomNav`     | нижняя навигация                                                                                           |
| `ChatList`      | список чатов                                                                                               |
| `ChatRoom`      | окно переписки                                                                                             |
| `PlacesManager` | вкладки «Метки» и «Группы» в разделе «Места»                                                               |

## Правила

- Виджет может импортировать фичи, `01.kit` и `00.shared`.
- Виджет не импортирует страницы.
- Импорты между виджетами нежелательны. Сейчас `Profile` и `MapControls` открывают `Settings` как модалку, это осознанное исключение.

## Когда выносить в виджеты

Блок переезжает сюда из фич, если он собирает несколько фич. Если же его импортирует другая фича, он остаётся в `02.features`, иначе получится импорт снизу вверх.
