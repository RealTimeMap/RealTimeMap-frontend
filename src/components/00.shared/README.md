# 00.shared

Самый нижний слой. Здесь лежит то, что не знает о бизнес-сценариях приложения. Импортировать отсюда может кто угодно, но сам `shared` не должен импортировать ничего из слоёв выше.

| Папка          | Что внутри                                                                                                                                                                         |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api/`         | HTTP-клиент (Axios), обёртка `apiService`, общие типы ответов. Подключается автоматически через `unplugin-auto-import`                                                             |
| `services/`    | Методы REST API, сгруппированные по доменам: `mark`, `user`, `chats`, `achievement`, `statistics` и т. д. Каждый домен состоит из `index.ts` с методами и `index.type.ts` с типами |
| `stores/`      | Глобальные Pinia-сторы: сессия пользователя (`auth`), чаты, места, настройки, диалоги, уведомления                                                                                 |
| `composables/` | Переиспользуемые хуки: сеть, WebSocket, геокодинг, высота вьюпорта                                                                                                                 |
| `lib/`         | Утилиты без UI: роутер, переходы страниц, кэш профиля, тема, i18n, даты, платформа                                                                                                 |

> `shared` не импортирует верхние слои. Исключение — `lib/router.ts`: он лениво подключает страницы и по смыслу относится к `06.app`.

## Офлайн-кэш API

`apiService.get` сохраняет успешные ответы в IndexedDB (`api/cache`). Если сервер недоступен или устройство офлайн, запрос возвращает последний сохранённый ответ вместо ошибки.

- Ключ кэша включает хэш токена, поэтому данные разных аккаунтов не смешиваются. При выходе из аккаунта и по кнопке «Очистить кэш» в настройках кэш очищается.
- Хранится не больше 500 ответов не старше 14 дней.
- Не кэшируются `/auth/*`, `/sessions`, `/profile/search`, а также `/personal/*` и `/group/*`: у «Мест» своё офлайн-хранилище с синхронизацией.
- Отключить кэш для отдельного запроса можно опцией `{ offlineCache: false }`.

## Офлайн-кэш картинок

- **Натив:** `lib/imageCache` (`useCachedImage`, `useCachedImages`) при первом показе скачивает картинку в `Directory.Cache/image-cache` (до 150 МБ) и дальше отдаёт локальный файл. Кэш входит в размер «Кэша» в настройках и очищается той же кнопкой. Если хост картинки не отдаёт CORS-заголовки, картинка показывается как обычно, но в кэш не попадает.
- **Веб:** картинки с других доменов кэширует service worker (правило `remote-images` в `vite.config.ts`, 200 записей, 30 дней).
- Общая логика Filesystem-кэша лежит в `lib/fileCache` (`createFileCache`); на ней же построен кэш тайлов карты `lib/mapCache`.
