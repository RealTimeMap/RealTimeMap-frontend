# features/app

Системные функции приложения, не привязанные к конкретному экрану.

| Слайс                  | Что делает                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------ |
| `AppUpdate`            | проверка новой версии и загрузка APK из GitHub Releases (подробнее в `RELEASING.md`) |
| `BugReport`            | сбор логов и отправка баг-репорта                                                    |
| `PushManager`          | регистрация push-уведомлений (Firebase)                                              |
| `NotificationProvider` | всплывающие уведомления внутри приложения                                            |
| `Onboarding`           | приветственный экран и подсказки (coachmarks)                                        |
