# 02.features

Фичи — это пользовательские действия и сценарии: создать метку, войти, подписаться, построить маршрут. Фича может содержать UI, состояние, запросы к API и валидацию.

## Группы

Слайсы разложены по группам (slice groups). Группа — это просто папка для навигации: у неё нет своего `index.ts`, и на правила импорта она не влияет.

| Группа                            | О чём                                                                               |
| --------------------------------- | ----------------------------------------------------------------------------------- |
| [`map/`](map/README.md)           | карта: ядро, слои, геолокация, маршруты, офлайн                                     |
| [`mark/`](mark/README.md)         | публичные метки: создание, редактирование, карточка, шеринг                         |
| [`places/`](places/README.md)     | личные метки и группы (раздел «Места»)                                              |
| [`auth/`](auth/README.md)         | авторизация, восстановление пароля, бан аккаунта                                    |
| [`profile/`](profile/README.md)   | всё вокруг профиля: достижения, подписки, геймификация, поиск людей                 |
| [`settings/`](settings/README.md) | отдельные пункты настроек                                                           |
| [`app/`](app/README.md)           | системные функции приложения: обновления, пуши, уведомления, онбординг, баг-репорты |
| [`info/`](info/README.md)         | информационные экраны: правила, юридические документы, роадмап                      |

## Структура слайса

```
<Slice>/
├── index.ts   публичный API: только то, что экспортировано здесь, можно импортировать снаружи
├── ui/        Vue-компоненты
├── model/     состояние, composables, типы
└── api/       свои запросы к серверу, если они не лежат в 00.shared/services
```

## Правила

- Фича импортирует `00.shared` и `01.kit`.
- Импорт виджетов и страниц запрещён.
- Импорты между фичами сейчас есть (например, `mark/MarkDetailSheet` использует `map/RouteToMark` и `mark/Share`), но новые лучше не добавлять. Если блок собирает несколько фич, его место в `04.widgets`.
- Импортировать фичу снаружи лучше через её `index.ts`, а не по внутренним путям.
