# features/settings

Отдельные пункты настроек. Экран настроек целиком собирается в `04.widgets/Settings`.

| Слайс            | Что делает                                |
| ---------------- | ----------------------------------------- |
| `ThemePicker`    | выбор темы оформления                     |
| `ActiveSessions` | список устройств, с которых выполнен вход |
| `SplashScreen`   | заставка при запуске и выбор её стиля     |
