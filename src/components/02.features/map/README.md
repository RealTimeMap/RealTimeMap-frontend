# features/map

Всё, что работает с картой MapLibre.

| Слайс            | Что делает                                                                             |
| ---------------- | -------------------------------------------------------------------------------------- |
| `MapCore`        | создание карты, стили, базовый вью; предоставляет инстанс карты через `provide('map')` |
| `MapLayers`      | переключение слоёв и стилей карты                                                      |
| `MapEditor`      | настройка видимых элементов управления карты                                           |
| `OfflineMap`     | офлайн-кэш карты на нативе: кастомный протокол MapLibre сохраняет ресурсы в Filesystem |
| `LandmarksLayer` | 3D-модели достопримечательностей (three.js)                                            |
| `Buildings3D`    | 3D-здания                                                                              |
| `Geolocation`    | получение позиции пользователя и экран без доступа к геолокации                        |
| `GetMarks`       | слой публичных меток: загрузка по границам экрана и обновления по WebSocket            |
| `RouteToMark`    | построение маршрута до метки                                                           |
