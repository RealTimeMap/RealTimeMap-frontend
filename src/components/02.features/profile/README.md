# features/profile

Фичи вокруг профиля. Сам экран профиля собирается в `04.widgets/Profile`.

| Слайс              | Что делает                           |
| ------------------ | ------------------------------------ |
| `AchievementsList` | полный список достижений с уровнями  |
| `Subscriptions`    | списки подписчиков и подписок        |
| `UserMarksList`    | все метки пользователя               |
| `Gamification`     | анимация получения опыта (`ExpGain`) |
| `SearchUsers`      | поиск пользователей                  |
| `EditProfile`      | редактирование имени, тега и аватара |
