# features/mark

Публичные метки, которые видят все пользователи.

| Слайс             | Что делает                                                      |
| ----------------- | --------------------------------------------------------------- |
| `MarkForm`        | форма создания метки: категория, описание, фото, срок жизни     |
| `MarkEditForm`    | редактирование существующей метки (использует стили `MarkForm`) |
| `MarkCreateMenu`  | меню создания метки по двойному касанию, в нескольких стилях    |
| `MarkDetailSheet` | карточка метки: комментарии, лайки, маршрут, шеринг             |
| `Share`           | шеринг метки картинкой со скриншотом участка карты              |
