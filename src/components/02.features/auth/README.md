# features/auth

| Слайс            | Что делает                                             |
| ---------------- | ------------------------------------------------------ |
| `Authentication` | вход, регистрация, OAuth, стор сессии (`useAuthStore`) |
| `ForgotPassword` | запрос на восстановление пароля                        |
| `AccountBan`     | экран заблокированного аккаунта                        |

> `useAuthStore` по смыслу является сущностью (сессия пользователя), а не фичей, поэтому его импортирует и `00.shared`. Если в проекте появится слой entities, стор стоит перенести туда.
